Modification Overview

1. MeatballCraft Adjustments

  • Ultimate Energy I/O Port: Increased energy storage & transfer speed (a lot). Make sure you enable speed limit when it's connected to flux networks.
  • ME Mythic Assembler: Support all types of energy input ports.
  • Mythic Chemical Reactor: Compatible with ME machinery input & output buses.
  • Mechanized Essentia Smeltery: Allow ME output buses.
  • Energy buses: Can be replaced with machine casing.
  • Sacred Cinders Apiary: Add some new recipes.
  • Definer 3.0: Added pattern provider support.
  • EIO Staff of Travelling: Reduced teleport cooldown time.
  • Creative ME Essentia Storage Cell: Added a recipe.
  • ME Mythic Assembler: Now can assemble paper with controller name.
  • Trinity Shard: Added a recipe of Seared Caster.
  • More Defined: Added Defined Chicken and some recipes.
